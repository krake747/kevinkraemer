# Discovery: crawlers, SEO, feeds, AI retrieval

Source of truth: `public/robots.txt`, `src/pattern/seo.tsx`, `src/core/site/`,
`src/routes/sitemap-*.ts`, `src/routes/llms-full.txt.ts`, `public/llms.txt`.

## Crawler policy

`public/robots.txt` is the list; prose never copies agent names. Allowed: search engines, retrieval
agents that cite pages, rendering variants, social unfurlers. Blocked: pure training crawlers and
high-volume scrapers. Live domain aligns with Cloudflare Content Signal
`search=yes,ai-train=no,use=reference`. `src/core/site/robots.spec.ts` guards the policy; verify
live with `pnpm check:agents --live`. A live-only 403 with a 200 origin means the block sits in
Cloudflare Bots, not in this repo.

## SEO and sitemap

Each page gets a unique title and description from one source of truth; see
`docs/adr/0007-seo-feeds.md`. Head, OpenGraph, Twitter card, and JSON-LD render from
`src/pattern/seo.tsx` with Person and BlogPosting schemas. `sitemap-0.xml.ts` emits one `loc` per
page, `sitemap-index.xml.ts` points at it; `noindex` routes such as `/search` are excluded. No
`lastmod`, `changefreq`, or `priority` today.

## AI retrieval files

Three text files: `public/llms.txt` summary, built `llms-full.txt` archive, and
`public/logs-llms.txt` section guide. Every log entry also ships `/logs/{slug}.md`, written by
`scripts/prerender.ts` from `src/core/content/markdown-document.ts` and preferred by the edge over
converting HTML; the entry page advertises it with `<link rel="alternate" type="text/markdown">`.
`e2e/negotiation.spec.ts` holds both ends to that promise.

`public/.well-known/agent-skills/kevinkraemer-com/SKILL.md` is the installable skill; its index at
`public/.well-known/agent-skills/index.json` is generated by `scripts/site-files.ts`, which digests
the bytes it points at. Add a new machine-readable file in `src/core/site/endpoints.ts` and the
catalog, linkset, `_headers`, and OpenAPI path follow; then link it from `public/llms.txt`.
